# GraphOps benchmark

Generated by `npm run eval -- 200` on 2026-10-18 against FalkorDB, with no LLM involved.
200 random fault worlds were injected into a `GRAPH.COPY` sandbox of the `acme` graph. 50 had a **silent root cause**
(the broken node raised no alert), 96 had an **unrelated noise alert**, and every world had **two decoy deploys** on unrelated
services, often newer than the real culprit. 127 worlds had a real culprit deploy on the root or on a direct dependent.

| Metric | Result |
| --- | --- |
| Root cause, top-1 (GraphOps graph ranking) | **72%** |
| Root cause, top-3 (GraphOps graph ranking) | **87.5%** |
| Baseline: blame the most recent deploy | **17%** |
| Baseline: pick a random alerting service | **22.5%** |
| Culprit deploy found (GraphOps, worlds with a culprit) | **84.3%** |
| Culprit deploy found (baseline: most recent deploy) | **50.4%** |
| Proof gate: true root VERIFIED | **71%** |
| Proof gate: true root REJECTED | **0%** |
| Proof gate: unrelated wrong claim wrongly VERIFIED (n=133) | **3%** |
| Proof gate: wrong claim on the same causal chain VERIFIED (n=67) | **29.9%** |

Run time: 356.2s. Reproduce with `npm run eval` (a fixed RNG seed gives the same worlds every run).

**How a world is built:** pick a random service that something depends on as the root. Alert it (75% of the time), alert each service
up to 4 hops upstream with probability 0.6, maybe alert one unrelated service, add the culprit deploy next to the root (70%) and two decoys.
**Proof gate check:** for each world we also claim a wrong root cause (often the noise service) and count how often the gate wrongly returns VERIFIED.
Wrong claims are split in two. *Unrelated* ones share no dependency chain with the true root, and the gate should never verify them.
*Same-chain* ones sit between the alerts and the root, or below the root. Topology alone cannot always separate those from the truth,
which is why the ranking also weighs alerts on the node itself, depth and nearby deploys.
